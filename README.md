SmartPaperAI 🚀
SmartPaperAI is an AI-powered document assistant designed to help users interact with PDF documents using natural language queries. It leverages Retrieval-Augmented Generation (RAG) with LangChain and Groq's Llama3 model for intelligent responses.
Features ✨
- 📄 PDF-based Retrieval: Extracts relevant information from uploaded PDFs.
- 🤖 AI Chatbot: Uses Groq's Llama3 model to generate responses based on retrieved content.
- 🏎 Optimized Retrieval: Uses HuggingFace embeddings and recursive character text splitting for efficient searching.
- 🎨 Modern UI: Streamlit-based interface with custom styling for an engaging experience.
- 🔄 Session History: Maintains conversation context for continuity.

Installation ⚙️
Clone the repository and install dependencies:
git clone https://github.com/your-repo/smartpaperai.git
cd smartpaperai
pip install -r requirements.txt


Usage 🚀
Run the Streamlit app:
streamlit run app.py


Upload a PDF file and enter your query in the chatbox to interact with the document.
Dependencies 📦
- Python 3.x
- Streamlit
- LangChain
- HuggingFace Embeddings
- Groq's Llama3 model
- PyPDFLoader
